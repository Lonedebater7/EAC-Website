# Studio Savior Privacy Update — 2026-09-19

The Studio Savior Privacy Policy now discloses the in-app feedback system.

It documents:
- voluntary feedback form content;
- app version, tier, installation/device identifier, and timestamp metadata;
- EAC email notifications for submitted feedback;
- optional account-email use when the user permits follow-up; and
- the explicit exclusion of automatic L5X / PLC project content from feedback submissions.

No application behavior is changed by this website-only update.
